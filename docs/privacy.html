[개발자 이름](이하 "개발자")은 안드로이드 키보드 앱 "말랑키"(패키지명 dev.malangkey, 이하 "앱")를 이용하는 분의 개인정보를 소중히 다루며, 「개인정보 보호법」 등 관련 법령을 지킵니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 핵심 요약

  • 말랑키는 인터넷 권한이 없는 오프라인 앱입니다. 앱이 외부 서버와 통신할 수 없습니다.
  • 키보드로 입력한 내용, 클립보드 기록, 사용자 사전 등은 사용자의 기기 안에만 저장되며 개발자를 포함한 누구에게도 전송되지 않습니다.
  • 개발자는 이용자의 개인정보를 수집·보관·제3자 제공하지 않습니다.

2. 기기 안에서만 처리되는 정보

아래 정보는 키보드 기능을 제공하기 위해 기기 내부(앱 전용 저장공간)에서만 처리됩니다. 개발자는 이 정보에 접근할 수 없습니다.

입력 중인 문자글자 조합(한글·일본어 등), 단어 추천저장하지 않음. 입력 처리 후 바로 사라집니다.

일본어 변환 학습 정보자주 쓰는 변환 후보를 앞쪽에 표시시크릿(Incognito) 모드에서는 학습하지 않습니다.
키보드 설정·테마사용자 맞춤 설정 유지앱 삭제 시 함께 삭제됩니다.
오류 기록앱 오류가 났을 때 원인 확인기기에만 저장되며, 사용자가 직접 공유하지 않는 한 전송되지 않습니다.

앱을 삭제하면 위 정보는 모두 기기에서 삭제됩니다. 앱은 Android 자동 백업도 사용하지 않습니다. 설정의 "백업" 기능은 사용자가 직접 저장 위치를 고를 때만 파일을 만듭니다.
